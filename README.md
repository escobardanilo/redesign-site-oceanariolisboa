Redesign — Lisbon Oceanarium Website

Study project focused on redesigning the interface, built with **pure HTML, CSS, and JavaScript**, based on the official website of the Lisbon Oceanarium, using AI tools (GitHub Copilot / Claude / ChatGPT) as part of the development process.

Objective

To practice front-end fundamentals (HTML semantics, responsive layout with CSS, and interactivity with JavaScript) by recreating and improving the visual experience of a real website — and, in parallel, training an AI-assisted workflow: code generation and review, debugging problems, and accelerating implementation decisions with the support of LLMs, while maintaining final architectural and design decisions.

AI Tools Used

- **GitHub Copilot / Claude / ChatGPT** — code snippet generation and review, refactoring and debugging suggestions
- Suggestions used to accelerate repetitive tasks (CSS structuring, responsiveness adjustments, JS organization), with manual review of each suggestion before application

Technologies

- HTML5
- CSS3
- JavaScript (Vanilla)

About the Project

This is a personal project for studying and practicing front-end development, also used as an AI-assisted workflow exercise (suggestions, review of generated code, and integration of LLM suggestions into daily programming). The redesign has no official link to the Lisbon Oceanarium — it is a conceptual proposal created for learning and portfolio purposes.

This was a test project, where I had no intention of continuing.
