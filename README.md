Redesign — Lisbon Oceanarium Website

Study project focused on interface redesign, built with **pure HTML, CSS, and JavaScript** based on the official website of the Lisbon Oceanarium, using AI tools (GitHub Copilot / Claude / ChatGPT) as part of the development process.

Objective

To practice front-end fundamentals (HTML semantics, responsive layout with CSS, and interactivity with JavaScript) by recreating and improving the visual experience of a real website — and, in parallel, to train an AI-assisted workflow: generating and reviewing code, debugging problems, and accelerating implementation decisions with the support of LLMs, while retaining the final architectural and design decision.

AI Tools Used

- **GitHub Copilot / Claude / ChatGPT** — code snippet generation and review, refactoring suggestions, and debugging
- Prompts used to accelerate repetitive tasks (CSS structuring, responsiveness adjustments, JS organization), with manual review of each suggestion before applying

Technologies

- HTML5
- CSS3
- JavaScript (Vanilla)

About the Project

This is a personal project for studying and practicing front-end development, also used as an AI-assisted workflow exercise (prompting, reviewing generated code, and integrating LLM suggestions into daily coding). The redesign has no official link to the Lisbon Oceanarium — it is a conceptual proposal created for learning and portfolio purposes.

There is also study and development for the Starlink website.
